# ai.parents.tv

父母tv，电视直播类Android TV

## 功能

- 央视+各省：基本上包括了央视全套的高清频道和国内各个省级的卫视。
- 地方频道：主要是各个省的地方频道，按照省份排列，内容有些多和杂，质量也层次不齐，这个主要是方便大家按照兴趣组合。
- 港澳台：搜集整理的香港、台湾和澳门以及一些海外华人频道，其中包括凤凰卫视、TVB、星空等一些深受大家喜欢的频道。
- 特色频道：主要包括了一些影视轮播、NewTV、CHC等特色频道
- 体育频道：主要包括五星体育、咪咕体育、劲爆体育等体育频道
- 国际频道：DISCOVERY、BBC、FOX News、CNN等国际频道

## 应用说明

爸妈TV 是一个面向 Android TV / 电视盒子的直播应用，使用 Kotlin + Jetpack Compose 开发，播放器基于 Media3 ExoPlayer，支持 HLS、DASH 与普通 TS 流。界面按遥控器方向键操作，适合大屏和长辈使用。

### 遥控器操作

- 首页：方向键移动焦点，OK 确认；左右切换侧栏与频道网格，侧栏内上下切换分类，顶部分组条左右切换省份/子类。
- 播放中：OK 显示控制栏，返回键先隐藏控制栏、再返回列表。
- 控制栏隐藏时：上/下键切换频道，菜单键收藏/取消收藏；这些按键动作可在「按键设置」中修改。
- 控制栏：收藏、上一个、暂停/播放、下一个、画面比例（适应/铺满/缩放）、选线、返回列表。

### 线路与容错

- 每个频道按「IPv4 优先、非地区限制优先、来源优先级」排序，内置目录最多合并 6 条线路，同一 URL 自动去重。
- 播放失败会自动切换下一条线路；某条线路超过 10 秒仍无画面会判定为无响应并继续切换。
- 全部线路失败时显示错误原因与「重试全部线路 / 返回列表」。
- 自动记忆上次观看的频道与分类，收藏与上次进度保存在本机 SharedPreferences。

### 线路自动更新

- App 启动后，若距离上次更新超过 12 小时，会在后台并行检查 7 个公开 IPTV 列表；每个源最多等待 8 秒连接、15 秒读取。
- 只给目录中同名频道追加新 URL，不新增/改名频道；已有线路保持在前，新线路追加在后，每个频道最多保留 8 条，自动去重；实测失效的线路在合并时按整串剔除（`CatalogUpdater.DEAD_STREAMS`）。
- 更新结果写入应用私有目录 `channels_live.json`，下次启动优先读取；内置目录比缓存新时（App 刚更新过）改以内置目录为底重新拼，否则旧缓存会一直盖住新版本新加的线路。线路集合有任何变化都落盘，包括只删不增的那次清理。
- 全部源失败时不写缓存，继续使用现有数据，不会清空可用线路。
- 设置页显示上次更新时间（北京时间）与结果，可点「立即更新线路」强制刷新；实测 7/7 个源可用时会补充数百条线路。
- 更新只处理公开 IPTV 列表，不绕过任何付费、会员或 DRM 保护。

### 关于咪咕

公开列表中提供的是咪咕直播 1–8 / 4K 等免费频道，App 已实测可播。咪咕会员专享赛事受版权与会员校验保护，本应用不提供绕过或抓取会员接口；需要观看会员场次请使用咪咕官方客户端并开通会员。

### 构建

环境要求：JDK 17、Android SDK 35（compileSdk 35 / targetSdk 34 / minSdk 23）。

```bash
export JAVA_HOME=/path/to/jdk-17
export ANDROID_HOME=/path/to/Android/Sdk
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Gradle Wrapper 的发行包地址在 `gradle/wrapper/gradle-wrapper.properties`，当前指向华为云镜像；如网络环境不同可自行替换。SDK 路径也可写入本地 `local.properties`（已被 .gitignore 忽略）。

### 更新频道目录

频道目录由脚本从公开 IPTV 列表抓取、解析、去重、归类后生成到 `app/src/main/assets/channels.json`：

```bash
python3 tools/build_catalog.py            # 在线抓取（带本地缓存）
python3 tools/build_catalog.py --offline  # 只使用 tools/.cache 中的缓存
```

重新生成后再次执行 `./gradlew assembleDebug` 即可打包。脚本会校验央视、卫视、港澳台、NewTV/CHC、体育、国际等代表频道是否齐全，缺失时返回非零退出码。

使用的公开数据源：fanmingming/live、vbskycn/iptv、zbefine/iptv、BigBigGrandG/IPTV-URL、YanG-1989/m3u、epg.pw（港/台/澳）、Kimentanm/aptv、iptv-org，以及行政区划数据 modood/Administrative-divisions-of-China。App 内自动更新另外使用 XiaoZhang5656、suxuang/myIPTV、zhanghong1983/TVBOXZY、YuanHsing/freed 的公开列表。参考项目：[dongyubin/IPTV](https://github.com/dongyubin/IPTV)。

### 全频道探测结果（2026-10-21，内置目录）

使用 `tools/probe_channels.py` 对本轮内置目录做了主机侧探测：先请求全部线路，再用 VLC 软件解码逐频道抽帧，并逐频道人工复核台标。探测是主机侧、单时点的，公开线路会随时间漂移，不代表电视端永久状态。读数取自两份快照：HTTP 快照 2026-10-21 16:23（北京时间），抽帧与复核到 2026-10-21 16:41（北京时间）。

计数口径有一处已知错位，先说明白：下面所有数字的 URL 集合来自 16:23 那一刻的目录（2004 个不重复 URL）；`app/src/main/assets/channels.json` 在 16:37:32 被 `tools/build_catalog.py` 重新生成过（现为 1328 频道 / 2039 条线路 / 2006 个不重复 URL），本节没有按新目录重跑探测。差异全部集中在辽宁体育一个频道：它的线路从 3 条变成 5 条（2037 → 2039，2004 → 2006 = 去掉 2 条、新增 4 条）。去掉的是 `59.44.102.18:8888/newlive/live/hls/45/live.m3u8` 与 `42.176.185.28:9901/tsfile/live/1007_1.m3u8`（这两条本轮探过、均响应超时）；新增的 4 条（bfgd 的 `httplive.slave.bfgd.com.cn:14311` playurl 直连、`39.134.61.218`、`hwottcdn.ln.chinamobile.com`、`39.135.129.162`）不在这 2004 条里，未进 VLC 抽帧；16:50 另做了一次逐条 HTTP 现读，见下面辽宁体育那条。

- 目录共 1328 个频道、2037 条线路、2004 个不重复 URL。
- HTTP 可达 518 个 URL（按频道逐条累计为 546 条线路），覆盖 468 个频道；其余 860 个频道在本机网络环境下没有一条可达线路。
- 468 个有可达线路的频道中，368 个成功抽到画面（每频道保留 1~3 帧：223 个 3 帧、19 个 2 帧、126 个 1 帧）；100 个线路可达但 VLC 解不出画面。
- 368 个有画面频道中，59 个画面异常：21 个无信号/黑屏、29 个测试卡/占位页/机顶盒菜单/版权限制页、9 个未见台标；其余 309 个可见台标或为正常节目画面（这 309 个仍含下条那个台标与频道名不符的频道）。
- 抽帧时见到不少购物、药品广告，其中多数带台标；带台标广告按正常直播时段处理，未从目录删除。9 个未见台标的频道里有画面看似正常节目的（如动画片尾、无台标直播画面），按「未见台标」列入待复核，没有直接判为广告。
- 可达性会漂移：上海新闻综合、上海都市、七龙珠、中华小当家、五星体育在 15:21 的 HTTP 快照线路可达并已抽到帧，16:23 快照其线路全部失败（连接被拒或响应超时），复测抽帧后这 5 个频道改判为「无可达线路」，不计入上面的 368。
- 修掉一处探测误判：部分 HLS 线路返回 `Content-Type: text/html; charset=UTF-8` 而正文以 `#EXTM3U` 开头，App 内 `StreamProbe` 与主机侧脚本曾把它判成「返回网页」直接丢弃。修正判据（先看正文再定性）后重跑全量 HTTP，并对剩余 15 条判为「返回网页」的 URL 逐条回读正文，0 条以 `#EXTM3U` 开头。
- 辽宁体育：主线路 `http://120.76.248.139/live/bfgd/4200000611.m3u8` 现读 HTTP 200、141 ms、正文以 `#EXTM3U` 开头（就是上一条那类被 `text/html` 标签误判的线路）；但清单内分片指向 `httplive.slave.bfgd.com.cn:14311`，本机 TCP 连接 6 s 超时，VLC 运行 24 s 内 0 帧。另两条线路（`59.44.102.18:8888`、`42.176.185.28:9901`）均为响应超时。16:37:32 重新生成的目录里辽宁体育是 5 条线路，逐条现读（2026-10-21 16:50 北京时间，本机）：第 1 条 200 / 151 ms 但分片主机 TCP 超时；第 2 条（`httplive.slave.bfgd.com.cn:14311` playurl 直连）连接超时 6016 ms；第 3、4、5 条（`39.134.61.218`、`hwottcdn.ln.chinamobile.com`、`39.135.129.162`）分别 HTTP 404 / 110 ms、404 / 27 ms、404 / 40 ms。也就是本轮这个时点 5 条线路没有一条能在本机出画面。本轮结论只能写成「playlist 有效、分片主机在本机不可达」，不等于该频道永久不可看：13:30 前后曾在 App 内实际播出过。
- 另发现个别源台标与频道名不符，例如「CGTN 法语」抽帧显示的是 CGTN ESPAÑOL。
- 本轮没有删除、改名或降权任何频道。逐条线路结果与逐频道结论保存在本机 `tools/.cache/channel_probe/`（已被 `.gitignore` 忽略）：`http_results.json` 为 2004 条 URL 的逐条读数，`channel_results.jsonl` 为 1328 行逐频道结论，`review.json` 逐条列明 59 个异常频道及其帧文件路径，`sheets/` 为覆盖 368 个有画面频道的 16 页缩略图。
- 端侧实测进度：v1.1.1 的 APK 已装在 AOSP TV 模拟器（`emulator-5554`，1920x1080）上跑通：首页 → 体育频道 → 辽宁体育进入播放，选线面板显示「共 5 条」、线路 1 为 `120.76.248.139`（141 ms），5 条都跑完后落到「已尝试 5 / 5 条线路」提示（模拟器所在网络拉不到任何一条的分片，只证明链路会走完，不证明能出画面）。真机（家里的电视或盒子）仍未实测。
- 遥控器按键在模拟器上只试了两下：方向下键会把焦点移到左侧菜单「我的收藏」，方向右键没有把焦点送进右侧频道网格；上面那轮播放与选线是用 `input tap` 点出来的，真实遥控器的焦点走位待家里实测。

复现命令：

```bash
python3 tools/probe_channels.py http --http-workers 32 --refresh-http
python3 tools/probe_channels.py capture --capture-workers 4 --max-attempts 2 --timeout 22
python3 tools/probe_channels.py sheets
```

`http`/`capture` 默认沿用本机缓存，加 `--refresh-http` 才重跑全部 URL；`capture` 按频道 id 续跑，要复测某个频道就从 `channel_results.jsonl` 删掉它那几行再执行。台标/广告判定是人工看 `sheets/` 缩略图后写回 `review.json` 的，脚本不自动判。
